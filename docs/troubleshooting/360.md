# 360 video and the Insta360 SDK

The SDK stitching described here is optional. Cutpoint never ships the SDK; see
[insta360-sdk.md](../insta360-sdk.md) for how to get and install your own copy and for its
full troubleshooting table.

## First steps

```powershell
cutpoint 360 status                      # is the SDK found, which version, does it start
cutpoint 360 stitch <project> --dry-run  # prints the commands; works without the SDK
```

If the SDK is missing or broken, `--pano-source studio` (an Insta360 Studio equirect export) or
`--pano-source dfisheye` (preview quality, visible lens seam) still render.

## Common problems

| Symptom | What to do |
|---|---|
| SDK not found | Extract it under `<CUTPOINT_HOME>\sdk\insta360\`, or set `pano.sdk_exe` or `CUTPOINT_INSTA360_SDK` to the executable. Check with `cutpoint 360 status` |
| `stitch FAILED: error: ...` | The text after `error:` comes from the SDK. The full output of each run is in `<stitched_dir>\logs\<stem>.log`. Check `pano.stitch_args` against Insta360's public parameter table |
| Stitching is very slow | The SDK may be encoding in software. Update the NVIDIA driver and keep `-enable_h265_encoder` for outputs above 4096 px wide |
| Not enough space for stitching | Set `pano.stitched_dir` to a drive with room (about 54 GB per hour, plus 20 GB spare) |
| Stitch timed out | Raise or remove `pano.stitch_timeout_s` |
| Framing drifts as the camera turns | The equirect was stitched with FlowState or has no sidecar. Restitch: `cutpoint 360 stitch <project> --clips NNN --force` |
| Visible lens seam along the horizon | You are rendering from `dfisheye`. Use an SDK stitch or a Studio export |
| Studio export ignored | It must be 2:1, the full clip length (within 1 s), and named with the clip's `VID_YYYYMMDD_HHMMSS` stem or `_NNN` number, in one of `pano.studio_dirs` |
| Clips are in the wrong order or have wrong times | Start times come from the file name and are read in the PC's time zone |
| Wrong horizon or view feels early or late | Try `pano.imu_offset_s` and `pano.level_strength` ([Configuration](../configuration.md#pano)) |
| Render is slow | Rendering runs at roughly 0.35-0.5 times realtime. `--pano-cmd-every 2` is faster but leaves shake on every other frame |

Do not paste SDK files, documentation or output (beyond the `error:` line) into issues.
